# Gerenciamento de Pedidos (Orders API)

Prototipo fullstack gerado para cadastro de pedidos, desenvolvido com React, Express, Prisma e PostgreSQL.

## Tecnologias Utilizadas

- **Frontend:** React, Vite
- **Backend:** Node.js, Express
- **Banco de Dados:** PostgreSQL, Prisma ORM

## Como Rodar o Projeto

### Backend
1. Entre na pasta `backend`: `cd backend`
2. Instale as dependências: `npm install`
3. Configure as variáveis no arquivo `.env` (DATABASE_URL, ORIGEM_DO_FRONTEND)
4. Sincronize o banco de dados: `npx prisma db push`
5. Inicie a API: `npm run dev`

### Frontend
1. Entre na pasta `frontend`: `cd frontend`
2. Instale as dependências: `npm install`
3. Inicie a aplicação: `npm run dev`
